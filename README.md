# Parameterized-3-Bit-ALU

This project implements a modular 3-bit Arithmetic Logic Unit (ALU) using both **Logisim (circuit-level simulation)** and **Verilog HDL (hardware description and verification)**, demonstrating fundamental concepts in digital logic design and computer architecture.

Course: CIE 239 – Digital Logic and Computer Architecture  
Institution: Zewail City of Science and Technology  
Semester: Summer 2025  

---

## 🚀 Project Overview

The project consists of a fully functional ALU capable of performing arithmetic, logical, shift, and comparison operations using a 4-bit selection control input.

The design was implemented and verified at two levels:

- Gate-level structural circuit design (Logisim)
- HDL-based implementation with simulation (Verilog + ModelSim)

---

## 1️⃣ Logisim Implementation – Structural Circuit Design

- Fully structural gate-level design
- Separate arithmetic, logic, shift, and comparator blocks
- Smart selection logic for operation control
- Circuit-level simulation and validation

### 📌 Concepts Demonstrated:
- Combinational logic design
- Multiplexer-based operation selection
- Shift logic implementation
- Comparator flag generation
- Digital circuit simulation

---

## 2️⃣ Verilog Implementation – HDL-Based Design

- Structural and behavioral modeling
- Vector-based signal implementation
- Always blocks and case-based selection
- Built-in testbench verification
- Waveform validation using ModelSim

### 📌 Concepts Demonstrated:
- Hardware Description Language fundamentals
- Modular digital system design
- Control signal implementation
- Testbench development
- Simulation-based verification

---

## 🛠 Design Highlights

- Modular architecture
- Optimized selection logic
- Reduced unnecessary switching activity
- Vector-based minimized bit-width design
- Dual-level implementation (Circuit + HDL)
- Fully tested and verified
